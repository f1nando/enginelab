# enginelab

**Сайт:** https://f1nando.github.io/enginelab/  
**Репозиторий:** https://github.com/f1nando/enginelab

Учебный веб-стенд для исследования двигателей. TypeScript, Vite, Canvas. Серверная часть не нужна.

## Запуск

Нужен Node.js 22.18+ (рекомендуется 24).

```sh
npm install
npm run dev
```

Открыть адрес, указанный Vite (обычно http://localhost:5173).

```sh
npm test       # тесты физической модели
npm run build  # проверка TypeScript и сборка в dist/
npm run preview
```

## Эксперимент

1. Выбрать двигатель, запустить стенд.
2. Выставить дроссель ползунком или кнопками **0%, 25%, 50%, 75%, 100%** под ним. Выбранная кнопка подсвечивается; промежуточные значения остаются доступны на ползунке. Выбрать передачу. N — свободное вращение без нагрузки от автомобиля.
3. Сравнить мощность на валу, момент, расход, скорость и обороты.
4. В режиме «Время» по умолчанию отображаются последние 30 секунд. Колёсико над областью графика меняет горизонтальный масштаб: вверх — приблизить, вниз — отдалить. Временное окно ограничено 2–300 с и следует за последними измерениями; в режиме «Обороты» масштабируется диапазон RPM относительно указателя. Перетаскивание мышью или пальцем перемещает окно по горизонтали. При просмотре истории запись продолжается, но выбранный участок остаётся на месте. Кнопка ▶ над графиком возвращает к последним данным, сохраняя масштаб. Двойной щелчок или кнопка сброса масштаба возвращает исходный вид текущего режима. Ctrl/Cmd + колёсико остаётся браузерным масштабированием.
   Нажатие на показатель над графиком, верхнюю легенду или подпись боковой шкалы включает/скрывает серию. Доступны мощность, момент, расход, обороты, скорость, передача и давление наддува (только для турбомоторов). Передача отображается ступенчатой линией, N = нейтраль. Скрытие линии и изменение масштаба не останавливают запись и не меняют данные CSV.
5. Режим «Обороты» показывает справочные кривые при полном дросселе, а не текущие измерения.
6. «Записать измерение» сохраняет снимок в журнал, включая название двигателя. Можно сравнивать разные моторы. Журнал сохраняется при сбросе и смене двигателя, но не при перезагрузке страницы. Экспортируйте его перед закрытием.
7. Основная кнопка CSV выгружает всю телеметрию текущего опыта с шагом около 0,1 с. Смена двигателя и сброс очищают текущую телеметрию.

Кнопка **PNG** над графиком сохраняет именно текущий видимый участок с выбранными линиями и масштабом. В изображение включены цветные легенды, боковые шкалы с единицами, название двигателя, автомобиль и диапазон оси X. Курсор и всплывающая подсказка в снимок не попадают. Разрешение учитывает плотность пикселей экрана; остановка эксперимента для экспорта не требуется.

Для турбированных двигателей показывается отдельный показатель **давления наддува в барах** — избыточное давление относительно атмосферного. Нажатие включает его линию на временном графике, с собственной шкалой, значениями под курсором и экспортом в PNG. Давление также записывается в CSV. Для атмосферных двигателей показатель и легенда скрыты (в CSV — 0). Это учебная оценка `0,9 × нормированное состояние наддува`, а не паспортное давление конкретной турбины; сохраняются задержка набора и спад после отпускания газа.

Клавиши (когда фокус вне элементов управления): ↑/↓ — дроссель, ←/→ — передачи, пробел — пуск/пауза.

Кнопка **«Гальмо» / Brake** действует, пока её удерживают мышью или пальцем. При фокусе на кнопке можно удерживать пробел или Enter. Торможение имеет приоритет над тягой и уменьшает скорость даже при полном дросселе; автомобиль не уходит в отрицательную скорость. На нейтрали тормоз замедляет автомобиль, но не свободно вращающийся двигатель. Отпускание кнопки, потеря фокуса окна, пауза, скрытие меню и сброс отпускают тормоз. Торможение в модели упрощено: положительная тяга компенсируется и добавляется замедление 7 м/с². Состояние тормоза записывается в измерения и CSV (0 или 100%).

## Модель

Каталог и опорные кривые: `src/engine.ts`. 20 двигателей:

- **Украинские:** ЗАЗ «Таврія» МеМЗ-245 (1,1 л), «Славута» МеМЗ-307 (1,3 л), «Запорожець» МеМЗ-968 (V4, 1,2 л).
- **Атмосферные:** Chevrolet LS3, Daewoo A15SMS, Honda K20A Type R, BMW M54B30, Ford Coyote 5.0, Honda F20C, BMW S85 V10, Porsche 4.0 GT3, Volkswagen AAA VR6.
- **Турбомоторы:** Volkswagen EA888, Toyota 2JZ-GTE, Subaru EJ257, Mazda 13B-REW, Nissan RB26DETT, Mitsubishi 4G63T.
- **Турбодизели:** Volkswagen 1.9 TDI ALH и Mercedes-Benz OM606.

Поддерживаются коробки с 4–7 передачами. Трансмиссия моделируется с ручным выбором ступени, независимо от типа реальной коробки. Отсечка у старых карбюраторных ЗАЗ — условный учебный ограничитель, а не утверждение о наличии такого устройства в оригинальном автомобиле. Характеристики и кривые приблизительные.

Момент линейно интерполируется по оборотам и масштабируется дросселем. Наддув имеет задержку. Особенность VTEC отражена в форме кривой момента. Мощность в метрических л.с.: `M × RPM / 7023,5`. Расход оценивается из мощности и удельного расхода, с холостым расходом и отключением подачи при торможении двигателем.

Ограничитель фиксирует обороты ровно на заданном пределе без снижения момента и отключения топлива. Показания момента остаются равны значению опорной кривой при текущем дросселе и наддуве; мощность вычисляется из этого момента и ограниченных оборотов. Скорость автомобиля ограничена значением, соответствующим пределу оборотов на выбранной передаче. После переключения вверх обороты снижаются естественным образом, и разгон продолжается. Сброс газа и краткий разрыв тяги при переключении сохраняются.

**Это условный учебный ограничитель, а не физически достоверная модель отсечки ЭБУ.** Фиксация оборотов при сохранении показаний мощности не моделирует баланс энергии и пропуски рабочих циклов. Режим выбран для удобного исследования характеристик на верхней границе диапазона. Естественное изменение момента по опорной кривой до предела остаётся, но дополнительного провала из-за ограничителя нет.

График использует сохраняющую форму кубическую интерполяцию между измерениями без выбросов за их диапазон. Исходные показания и CSV не сглаживаются и не подменяются. Передача остаётся ступенчатой. Участки действия ограничителя слегка подсвечены. При наведении вертикальный курсор и цветные точки следуют точно за указателем; общая подсказка показывает время (или RPM) и значения всех включённых линий. Между замерами значения вычисляются по отображаемой кривой, что отмечено в подсказке. Передачи не интерполируются. В пустой области без записанных данных точки и подсказка не показываются.

На передачах сила на колёсах зависит от передаточного числа, главной передачи и КПД 0,88; ускорение — от условной массы, сопротивления качению, аэродинамики и дополнительной нагрузки стенда. Нагрузка регулируется ползунком **0–100%**, начальное значение — **25%**. Выбранная нагрузка сохраняется при сбросе опыта и смене двигателя. Это настройка дополнительного сопротивления, а не процент мощности двигателя; само сопротивление зависит от скорости. На нейтрали дополнительная нагрузка не действует. Радиус колеса — 0,32 м. Старт использует условное проскальзывание сцепления, смена передачи — краткий разрыв тяги.

**Это не инженерная модель.** Значения паспортных характеристик ориентировочные; нет температуры, сцепления шин, износа и детальной модели ЭБУ. Скорость расчётная. У каждой включённой серии графика собственная шкала слева или справа, окрашенная в цвет линии. На узком экране названия шкал сокращены до P (мощность), M (момент), Q (расход), n (обороты), v (скорость), G (передача), p (наддув). Полные названия остаются над графиком. В режиме «Обороты» доступны только справочные кривые мощности и момента; выбор остальных линий сохраняется для возврата в режим «Время».

Интерфейс чёрно-белый, цвет используется для линий графика и их обозначений. Рабочая область всегда занимает окно без прокрутки страницы. Кнопка в углу графика включает режим «Только график». На компьютере настройки собраны справа, на телефоне кнопка «Параметры» открывает боковое меню поверх графика. Меню закрывается крестиком, нажатием на затемнение или Escape. При недостаточной высоте меню и диалоги прокручиваются внутри, не сдвигая график.

Внешние шрифты и другие сетевые ресурсы не используются.

## GitHub Pages

Исходный код находится в ветке `main`, готовый сайт — в `gh-pages`. GitHub Pages настроен на публикацию из корня `gh-pages`. Относительные пути сборки поддерживают размещение в `/enginelab/`.

Для обновления нужны Git, GitHub CLI (`gh auth login`) и права записи в репозиторий:

```sh
npm test
npm run deploy
```

Команда собирает сайт и обычным коммитом обновляет `gh-pages`, без force push. Исходники в `main` нужно коммитить и отправлять отдельно. Скрипт использует временную папку внутри проекта и удаляет только её после публикации. GitHub Pages обновляет сайт не мгновенно.

Языки интерфейса — English (EN) и українська (УК). Переключатель находится в верхней панели; выбор сохраняется в браузере. По умолчанию используется английский; ранее сохранённый выбор украинского сохраняется. Смена языка не сбрасывает эксперимент и журнал. Подписи графика, единицы, справка, журнал и заголовки CSV переводятся вместе с интерфейсом. В английской версии PS обозначает метрические лошадиные силы (та же единица, что «к.с.»). Метаданные сайта и OG/Twitter-превью всегда на английском и не меняются при переключении языка интерфейса.
